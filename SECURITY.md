# Security

- This is a class demo with synthetic data. Do not enter real personal information.
- **Never commit secrets** (API keys, Supabase team keys, tokens, `.env` files). `.gitignore` blocks the common ones; double-check `git status` before committing.
- If a key is committed by mistake, tell the maintainers straight away and **rotate the key** with its provider. Deleting the commit is not enough, because the repository is public.
- To report a problem privately, message the maintainers in the cross-team Teams group instead of opening a public issue.
